# Chinese Female Commercial Short Fiction Skills

Two Codex skills for developing and reviewing Chinese female-audience commercial short fiction. The materials prioritize reader emotion, clear stakes, active heroines, escalating conflict, frequent payoffs, and concrete consequences for antagonists.

## Included skills

- [`female-commercial-short-fiction-editor/`](female-commercial-short-fiction-editor/SKILL.md): develops ideas into outlines, chapter cards, and complete short fiction; also includes commercial review modes.
- [`auditing-female-commercial-short-fiction/`](auditing-female-commercial-short-fiction/SKILL.md): reviews ideas, outlines, chapters, drafts, and underperforming manuscripts, with diagnosis and rescue-or-abandon guidance.

Each skill directory includes its references and agent metadata. Keep the directory structure intact so relative references continue to work.

## Use with Codex

Copy either skill directory into your Codex skills directory. Invoke the skill by name or provide a story idea, outline, chapter, or draft and ask Codex to create or review it.

## Language

The skill instructions are primarily written in Chinese, with some English metadata and guidance.
