# 女频商业短篇小说创作与审稿 Skills

本仓库提供两个用于 Codex 的中文女频商业短篇小说技能，覆盖从创意评估、故事大纲、章节设计到正文创作，以及商业审稿、问题诊断和旧稿救稿。

技能以读者情绪和商业爽感为核心，重点关注明确的现实利益冲突、女主主动反击、持续升级的对抗、阶段性爽点，以及反派承担具体代价。

## 技能列表

### 1. 女频商业短篇编辑与创作

目录：[female-commercial-short-fiction-editor](female-commercial-short-fiction-editor/SKILL.md)

适用于故事灵感评估、大纲设计、章节卡制作、短篇正文创作，以及商业化审稿。工作流会检查女主的现实目标和收益、反派恶行与最终损失、情绪曲线和爽点兑现。

### 2. 女频商业短篇审稿与诊断

目录：[auditing-female-commercial-short-fiction](auditing-female-commercial-short-fiction/SKILL.md)

适用于灵感、大纲、单章、完整稿及被拒稿或表现不佳的旧稿。除全局商业检查外，也提供废稿失败原因分类、可救程度判断和分优先级的修改方案。

## 安装与使用

将需要的 skill 文件夹完整复制到 Codex skills 目录中，保留其中的 `SKILL.md`、`references/` 和 `agents/` 文件。然后在 Codex 中按技能名称调用，或提供故事灵感、提纲、章节和全文并说明需要创作或审稿。

## 目录结构

```text
female-commercial-short-fiction-editor/
  SKILL.md

auditing-female-commercial-short-fiction/
```
