# 案例对照卡

审稿时选择题材最接近的案例机制，不套用原情节。

| 案例 | 可对照的商业机制 |
|---|---|
| 恶婆婆 | 先用具体恶行定反派等级，再以财产与家庭权力清算。 |
| 空调邻居 | 极端越界要求要在开篇给出，并通过现实代价完成反制。 |
| 男同事得知我贤惠 | 职场/婚恋标签化压迫，女主必须用边界和利益反击。 |
| 二婶 | 亲属道德绑架应连续升级，不能只靠口头翻脸。 |
| 照顾住院婆婆 | 照护责任转嫁需要量化时间、金钱与职业损失。 |
| 家里给妹妹建小群 | 原生家庭偏心要落到资源分配、信息排除与最终回收。 |
| 老公不是公婆亲生 | 身世真相应改变继承、房产或关系权力，不能只当八卦。 |
| 贫困生茶叶 | 善意被利用时，反击要证据化并带来名誉或经济后果。 |
| 瘫痪婆婆 | 长期照护压迫应让照护者回到法定/应负责任者身上。 |
| 爸妈各偏心一个姐妹 | 姐妹竞争要从偏爱展示推进到资源、责任和边界的重新分配。 |

比较维度：开篇 300 字冲突密度、反派升级次数、爽点间隔、女主收益、反派具体损失。
